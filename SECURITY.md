# Security Policy

## Supported Versions

Only the `4.x` line receives security fixes. The `3.x` and `2.x` lines are end of life.

| Version | Supported          | Notes                                        |
|---------|--------------------|----------------------------------------------|
| 4.x     | :white_check_mark: | Current line, fixes are released from `4.x`  |
| 3.x     | :x:                | End of life, no security fixes               |
| 2.x     | :x:                | End of life, no security fixes               |

## Reporting a Vulnerability

Report vulnerabilities privately, either through
[GitHub's private vulnerability reporting](https://github.com/serbanghita/Mobile-Detect/security/advisories/new)
or by email to Serban Ghita `<serbanghita AT gmail DOT com>`. Please do not open a public issue for an unpatched vulnerability.

The usual response time is 1 week for lower impact security reports.

Thank you!
